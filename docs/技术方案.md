# O2 工作台 — 技术方案

## 一、项目概述

### 定位
一个统一的 Web 工作平台，集成 O2OA 办公功能 + 自定义工具集，供团队多人使用。

### 目标
- 替代 O2OA 自带前端（太丑、功能冗余）
- 集成自定义工具（exe/py），用户浏览器即可使用
- 支持多人同时使用，任务隔离运行
- 部署在服务器/独立电脑上，用户零安装

---

## 二、技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| **前端** | Vue 3 + Element Plus | 组件丰富，适合后台管理类应用 |
| **状态管理** | Pinia | Vue 3 官方推荐 |
| **HTTP 客户端** | Axios | 成熟可靠 |
| **后端** | Python + FastAPI | 快速开发，原生支持异步，自动生成 API 文档 |
| **任务调度** | Celery 或 自建进程池 | 异步执行用户提交的工具任务 |
| **认证** | 对接 O2OA 的 JWT Token | 复用现有用户体系 |
| **数据库** | SQLite（起步）/ PostgreSQL（后续） | 存放用户配置、任务记录等 |
| **部署** | Docker Compose | 一键部署，环境隔离 |

## 四、核心模块设计

### 4.1 认证模块

复用 O2OA 的用户体系，所有用户账号在 O2OA 中管理。

```
用户登录 → FastAPI 用 O2OA API 验证 → 
获取 O2OA Token → 生成 Session Token → 
前端请求带 Token → 后端验证通过后转发到 O2OA
```

**关键点：**
- 登录接口直接调 O2OA 的 `/authentication`
- 后端用 O2OA Token 调用 O2OA API（以管理员身份）
- 后端为每个前端用户生成短时效 Session Token
- Token 过期自动刷新

### 4.2 OA 模块

通过后端代理转发 O2OA API，不直接暴露给前端。

**功能列表：**
- ✅ **待办列表** — 查看+处理待办
- ✅ **已办列表** — 查看已处理
- ✅ **待阅列表** — 查看+确认待阅
- ✅ **发起流程** — 选择流程 -> 填表单 -> 提交
- ✅ **内容查看** — 查看栏目/分类/文档
- ✅ **通讯录** — 人员/组织/群组查询

**不做的功能：**
- ❌ 表单设计器（仍在 O2OA 原生界面做）
- ❌ 流程设计器
- ❌ 系统管理（数据备份、日志查看等）

### 4.3 工具模块

核心机制：**后端进程池 + 任务队列 + 结果存储**

#### 工作流

```
用户点"运行工具"
  → 前端 POST /api/tools/run { tool_id, params }
  → 后端创建任务记录（状态: pending）
  → 放入队列排队
  → 轮到后启动子进程执行工具
  → 实时推送日志到前端（WebSocket）
  → 执行完毕 → 结果存到服务器目录
  → 状态更新为 completed / failed
  → 前端展示结果（文件/截图/日志）
```

#### 任务隔离
- 每个工具在独立子进程中运行
- 分配独立的临时工作目录
- 最大并发数可配置（防止资源耗尽）
- 超时自动 kill（防止僵尸进程）

#### 工具注册
每个工具需要一个描述文件（JSON），格式如下：

```json
{
  "id": "zidongv13",
  "name": "自动填商品件数",
  "description": "批量填写商品件数到抖店",
  "type": "exe",
  "path": "C:\\tools\\zidongv13.exe",
  "params": [
    { "name": "file", "type": "file", "label": "Excel文件" },
    { "name": "platform", "type": "select", "label": "平台",
      "options": ["精选平台", "拼多多", "京东", "抖店"] }
  ],
  "timeout": 300,
  "maxConcurrency": 1,
  "outputType": ["file", "log"]
}
```

## 七、部署方案

### 开发阶段
```
前端: npm run dev → localhost:5173
后端: uvicorn main:app → localhost:8000
直接跨域调用
```

### 生产部署
```
Docker Compose：
  - nginx（反向代理 + 静态文件）
  - backend（FastAPI + uvicorn）
  两个容器，一条命令启动
```

### 硬件需求
- **CPU**：4 核以上
- **内存**：8GB 以上（O2OA 本身吃不少）
- **硬盘**：SSD，取决于附件存储量
- **OS**：Windows Server（因为工具有 exe）/ 或 Linux（如果工具都能改 Python）
